# foc-compute-poc

Two public pages for the PieceWork proof of concept — compute bought from the storage provider that already
holds your data, on Filecoin Calibration.

- **[client/](https://lucaniz.github.io/foc-compute-poc/client/)** — the client itself, running entirely in your
  browser. Connect a wallet on Calibration and buy compute from a real storage provider. Nothing is installed,
  and nothing runs on anyone's server: your browser talks to the provider and to the chain.
- **[/](https://lucaniz.github.io/foc-compute-poc/)** — the guided walk-through, forwarded to whichever address
  the demo is served from at the time. It only works while that machine is up.

Code: <https://github.com/lucaniz/foc-compute> (private).
